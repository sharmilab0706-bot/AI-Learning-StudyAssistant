# AI-based learning assiatant

## Project Overview

AI Learning & Study Assistant is an AI-based application designed to help students with their daily learning activities.

## Features

- 📚 Doubt Clarification
- 🎯 Study Plan Generation
- 📖 Knowledge-Based Question Answering
- 🧠 Memory
- 📝 Quiz Generation
- 🤖 AI Agent

## Technologies Used

- Python
- Generative AI
- RAG
- Agentic AI
- Streamlit

## Objective

The main objective of this project is to provide students with an intelligent and easy-to-use learning assistant.

## Future Enhancements

- Voice-based learning
- Multiple language support
- Student progress tracking
- Mobile application
- Personalized learning recommendations
